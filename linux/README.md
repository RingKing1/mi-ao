# 米遥 (MI-AO) Linux 版使用指南

把小米蓝牙遥控器 2 Pro 变成 Linux 上的 AI 语音遥控仙女棒与无线飞鼠手柄。

---

## 核心特性

- **打字框实时流式输出**：按住语音键说话时，以 ~0.2s 超低延迟在当前光标所在的输入框实时流式输出字词，松手后终态高精度模型自动校准。
- **一键确认发送**：松手后按下遥控器中间的 **OK / 确认键**，直接模拟 Enter 回车发送，无需再碰键盘！
- **纯算法解码**：1:1 移植官方 IMA/DVI ADPCM 算法，无平台私有依赖。
- **GATT 语音桥接**：基于 Linux BlueZ 原生 D-Bus，稳定运行 ATVV v1.0 状态机。
- **双阶 Whisper 引擎**：流式极速响应 + 终态精准校准，内存直传采样点推理，启动自动消除冷启动延迟。
- **硬件级按键独占**：基于 Linux `evdev` (`EVIOCGRAB`) 独占设备，彻底屏蔽系统原生按键副作用。
- **Wayland 原生兼容**：基于 Linux 内核 `/dev/uinput` 虚拟设备与系统剪贴板，完美兼容 GNOME Wayland 桌面。
- **systemd 守护进程**：开机后台静默自启，随时拿起遥控器即用。

## 常用管理命令

安装后可直接在任意终端运行：

```bash
mi-ao status    # 查看遥控器连接与服务状态
mi-ao start     # 启动后台守护服务
mi-ao stop      # 停止后台服务
mi-ao restart   # 重启后台服务
mi-ao logs      # 实时监听语音输入日志
mi-ao enable    # 设置开机/登录自动启动
mi-ao disable   # 取消开机自启
mi-ao test      # 在前台测试运行
```

## 遥控器操作指南

默认模式为【实时打字与确认发送模式】：

| 遥控器按键 | 默认功能说明 |
| --- | --- |
| **语音键** | **按住说话，打字框内实时逐字输出；松手完成精准校准** |
| **OK / 确认键** | **确认发送（模拟键盘 Enter 回车键）** |
| **方向环** | **移动鼠标指针**（带平滑长按加速曲线，方便移动到输入框） |
| **返回键** | **取消 / ESC 键** |
| **音量 +/- 键** | **鼠标滚轮上下滚动** |
| **TV 键** | **模式切换**（在【通用打字】、【终端打字】、【飞鼠点击】与【键盘方向键】模式间循环切换） |
| | - **通用打字模式 (TYPING)**：使用 `Ctrl+V`，适用于 Chrome 检索框、网页、聊天软件与常规 GUI 文本框 |
| | - **终端打字模式 (TERMINAL)**：使用 `Ctrl+Shift+V`，专门解决 Linux 终端命令行中无法直接用 `Ctrl+V` 粘贴的问题 |
| | - **飞鼠点击模式 (MOUSE)**：OK键为鼠标左键，返回键为右键 |
| | - **键盘方向键模式 (DIRECTIONAL)**：方向环映射为键盘上下左右键 |

## 结果输出位置

- **当前活动窗口**：打字框内实时流式输出。
- **剪贴板**：自动将最新识别文字放入系统剪贴板（推荐安装 `sudo apt install -y wl-clipboard`）。
- **最新文本文件**：`linux/recordings/latest_transcript.txt`
- **历史记录**：`linux/recordings/history.jsonl`
- **录音音频备份**：`linux/recordings/speech_YYYYMMDD_HHMMSS.wav`
